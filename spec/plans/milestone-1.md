# תוכנית — Milestone 1: בסיס הפרויקט ומסכי האפליקציה

**מטרה:** אפליקציה שרצה מקומית עם שני מסכים מעוצבים (״משחק״ ו״אודות״), ניווט ביניהם ללא רענון, ולוח Simon עגול לא פעיל. המשחק עצמו עדיין לא פועל.

## 1. מה נכנס ומה לא

**נכנס:** פרויקט Vite + TypeScript + CSS; ניווט בין שני Views; מסך משחק במצב התחלתי (כותרת, הוראה, לוח, ״התחל״); מסך אודות; עיצוב לפי DESIGN.md; RTL; התאמה למובייל.

**לא נכנס (שייך ל-Milestones הבאים):**
- כפתור ״הפעלת צלילים״ וכל שמע — Milestone 3.
- כפתור ״התקן אפליקציה״, Manifest, Service Worker, GitHub Actions, `base` של GitHub Pages — Milestone 4.
- לוגיקת משחק, רצפים, שלבים, חלונית ״משחק חדש״ — Milestone 2. ב-M1 לחיצה על ״התחל״ אינה עושה דבר (הכפתור קיים ויזואלית בלבד).
- אין `vite-plugin-pwa`, אין Vitest (יתווסף ב-M2), אין אייקון מידע בפינה.

## 2. הערות על פערים בין המקורות (הוחלט לפי כללי ההכרעה)
- ה-Wireframes מציגים כבר במסך ההתחלתי כפתורי ״הפעלת צלילים״ ו״התקן אפליקציה״, אך MILESTONES.md מגדיר את המסך ההתחלתי של M1 בלי הכפתורים האלה (הם נבנים ב-M3/M4). נבנה לפי MILESTONES.md.
- אייקון המידע שב-Mockup לא נכלל; ב-״אודות״ התפריט מסמן ״אודות״ כפעיל (DESIGN.md סעיף 2.6).
- טקסט אודות: נשתמש בנוסח ה-Wireframes/Mockups, מותאם ל-PRD (כולל ״שלב 10״ ושהמשחק מסתיים בטעות הראשונה):
  - על המשחק: ״משחק זיכרון קלאסי שבו עליך לצפות ברצף צבעים ולחזור עליו באותו סדר. בכל שלב נוסף צבע אחד, והמהירות עולה בהדרגה.״
  - הוראות (5 פריטים): 1) לחצו על ״התחל״ כדי להתחיל משחק חדש. 2) צפו ברצף הצבעים המוצג. 3) חזרו על הרצף באותו סדר. 4) בכל שלב נוסף צבע אחד והמהירות עולה. 5) נסו להגיע עד שלב 10!
  - יוצרת האפליקציה: ״אוה סוקולובסקי״.

## 4. גישה

**ניווט (`nav.ts`):** שני אלמנטים `<section>` — משחק ואודות — שניהם נשארים ב-DOM; מחליפים רק `hidden`. כך מצב המשחק לא יאבד ב-M2/M3. תפריט `<nav>` עם שני כפתורים (`aria-current="page"` לפעיל). בלי URL routing ובלי hash. סדר RTL: ״משחק״ מימין, ״אודות״ משמאל (קורה אוטומטית עם `dir="rtl"` ו-flex).

**לוח (`board.ts`):**
- מעטפת עגולה כהה (`#111111`) עם מסגרת עבה, ועיגול מרכזי כהה.
- ארבעה כפתורי `<button>` מונחים זה על זה, כל אחד מכיל SVG (viewBox 200×200) עם מסלול (path) של רבע-טבעת אחד; אדום למעלה, כחול ימין, צהוב למטה, ירוק שמאל; רווחי הפרדה שחורים בין המקטעים.
- ה-hit-area של כל כפתור מוגבל לצורת הקשת (`pointer-events` על ה-path בלבד), כך שהלחיצה נופלת על הרבע הנכון.
- `disabled` + `aria-label` בעברית (״אדום״, ״כחול״, ״צהוב״, ״ירוק״). אין hover/active/pressed (לפי PRD אין שינוי חזותי בלחיצה). שמירת `:focus-visible`.
- הברקות/צל בסגנון ה-Mockup בעזרת gradient עדין וצל פנימי; צבעי הבסיס מה-Style Guide.
- מחלקת `.lit` מוגדרת ב-CSS לשימוש ב-M2 (הארה בלבד), אך לא בשימוש עדיין.
- גודל: `width: min(100%, 340px)`, `aspect-ratio: 1`; מרכוז.

**עיצוב:**
- רקע עמוד `#F8F8F8`; טקסט `#111111`; משני `#9CA3AF`; מרווחים בכפולות 8px; רדיוס 16/12px.
- H1 32px Bold ממורכז; H2 24px; גוף 16px; Heebo לעברית עם Inter כגיבוי.
- ניווט: מסגרת מעוגלת, שני פריטים שווים; פעיל — רקע כהה וטקסט לבן; לא פעיל — בהיר וטקסט כהה; קו הפרדה עדין מתחתיו.
- כפתור ״התחל״: Primary, רחב, פחם, טקסט לבן מודגש, רדיוס 16px, צל עדין; גובה מינימלי 56px.
- מסך אודות: כרטיס ״הוראות המשחק״ עם רשימה ממוספרת בעיגולים צבעוניים (אדום, ירוק, כחול, צהוב, אפור-כחלחל), קו מפריד ו״יוצרת האפליקציה״. תוכן יישור לימין.
- Mobile First: `overflow-x: hidden` כמגן אחרון בלבד; בדיקה שאין גלילה אופקית ב-320–430px; `padding` עם `env(safe-area-inset-*)`; יעדי מגע ≥ 44px; שימוש ב-`min-height: 100dvh`.
- כל הטקסטים בעברית; הערות בקוד באנגלית; טקסט דינמי עם `textContent`.

## 5. סדר עבודה
1. אתחול פרויקט: `package.json`, `tsconfig`, `vite.config.ts`, `index.html`; `npm install`.
2. קובצי tokens/base ושילוב גופנים.
3. ניווט + שלד שני המסכים.
4. מסך משחק עם הלוח.
5. מסך אודות.
6. בדיקה בדפדפן (רוחב 375 ו-320, RTL, ניווט הלוך ושוב, צילום מסך מול Mockups).
7. עדכון "פקודות הרצה" ב-CLAUDE.md; סימון 🟡 ב-MILESTONES.md בסיום הבנייה.

## 6. בדיקות מול Definition of Done
| תנאי | איך נבדוק |
|---|---|
| `npm install`, dev ו-build עוברים | הרצת `npm install`, `npm run dev`, `npm run build`, `npm run typecheck` |
| בדיוק שני מסכים וניווט ללא Refresh | בדפדפן: מעבר הלוך ושוב; ווידוא שאין טעינת דף (אין אירוע load חדש) |
| ארבעת הצבעים בפריסה העגולה, לא מגיבים | לחיצה על הרבעים — אין שינוי ואין אירוע; כולם `disabled` |
| אודות: תוכן ושם היוצרת, עברית ו-RTL | בדיקה חזותית וב-DOM (`dir="rtl"`, `lang="he"`) |
| התאמה ל-Wireframes/Style Guide/Mockups | השוואת צילומי מסך |
| אין גלילה אופקית; מגע ונגישות | בדיקת `scrollWidth` ב-320/375/430px; גודל יעדי מגע; ניווט מקלדת |

**מה לא ייבדק ב-M1:** מכשיר iPhone/Android אמיתי (בדיקת מובייל תהיה בדפדפן עם מצב מובייל; בדיקה במכשיר אמיתי אפשרית אצלך לפי ״הרץ כדי שאבדוק״).
